# Site ONG

Projeto desenvolvido como atividade acadêmica utilizando HTML e CSS.

## Sobre o projeto

O site representa uma ONG e possui páginas para apresentação da organização, projetos sociais e cadastro de voluntários.

## Tecnologias utilizadas

- HTML5
- CSS3

## Funcionalidades

- Página inicial
- Página de projetos
- Formulário de cadastro
- Navegação entre páginas
- Validação de campos
- Estrutura semântica em HTML
- Site publicado com GitHub Pages
